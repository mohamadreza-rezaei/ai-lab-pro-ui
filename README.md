# AI Lab Pro UI

Static dashboard UI for **AI Lab Pro** — agents, DevOps views, and monitoring surfaces.

**Live:** https://ai-lab-pro.pages.dev/

## Stack

- HTML / CSS / JavaScript
- Webpack (dev + production configs)

## Run locally

```bash
npm install
npm start
```

Build for production:

```bash
npm run build
```
